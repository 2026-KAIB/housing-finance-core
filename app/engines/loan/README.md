# Loan engine — 근거 문서 발췌

`app/engines/loan/formulas.py`와 `tests/loan_engine/`의 코드 주석이 인용하는
"DESIGN SSOT"는 팀 설계 문서(`single_source_of_truth.md`)를 가리킨다. 그 문서
전체는 아직 이 저장소 밖에만 있어서 다른 팀원이 골든케이스·공식 원문을 검증할
방법이 없었다. 이 파일은 **대출 계산 엔진이 실제로 쓰는 부분만** 그대로 옮겨
둔 것이다 (2026-07-24 기준 발췌, 전체 문서 아님).

## §13.1 자격·안전조건 필터 (필수조건)

하나라도 미충족 시 점수와 무관하게 제외:
1. 연령·소득·혼인·무주택 등 신청자격
2. 대상 주택가격·면적
3. 상품별 대출한도
4. LTV·DTI·DSR 조건
5. 필요 자기자본 보유 여부
6. 구매 후 비상자금 유지 여부
7. 구매 후 월 현금흐름 ≥ 0 (정확히는 ≥ Buffer)

정책대출 자격·법정 한도는 점수 항목이 아니라 통과 필수조건이다.

## §13.2 DSR 공식

```
DSR = 연간 모든 금융부채 원리금 상환액 ÷ 연간 소득
```
**[C-12 확정]** DSR의 "모든 금융부채"는 **기존 대출 + 신규 대출(해당 시뮬레이션 대상)**을 모두 포함한다.

## §13.3 원리금균등 월 상환액

대출원금 `L`, 월금리 `i`, 총 상환기간 `n개월`:
```
PMT = L × {i(1+i)^n} ÷ {(1+i)^n − 1}
```
**[규약]** 대출 월금리는 명목환산 `i = 연이율 ÷ 12` (예적금의 실효환산과 다름).

## §9.1–9.2 대출 가능액과 필요 자기자본

```
LoanMax = min(상품 한도, LTV 한도, DTI 한도, DSR 한도, 실제 필요 대출액)
EquityTarget = 총 구매 필요금액 − LoanMax
```
비상자금은 주택구매자금에서 제외한다. 구매 직후에도 일정 비상자금이 남아야 한다.

## 부록 A-2. 대출 가능액 이분 탐색 (9·13장)

```
입력: LTV상한, 기존DSR분자(연), 연소득, 안전DSR, 구매후소득/생활비, Buffer, 금리, 만기
Step 1  하한 lo = 0, 상한 hi = min(LTV 한도, 상품 한도, DTI 한도, 실제 필요액)
Step 2  while (hi − lo) > ε:            # ε = 100,000원
            L = (lo + hi) / 2
            pmt = PMT(L, i=연이율/12, n)          # 13.3
            dsr = (기존 연상환 + pmt×12) / 연소득  # 기존+신규 (C-12)
            잔여 = 구매후소득 − 구매후생활비 − 모든대출월상환(pmt 포함)
            feasible = (dsr ≤ 안전DSR) and (잔여 ≥ Buffer)   # 13.1의 6,7 포함
            if feasible: lo = L      # 더 큰 대출 시도
            else:        hi = L
Step 3  return lo   # LoanMax
```
단조성: L 증가 → pmt·dsr 증가, 잔여 감소 → feasible는 L에 대해 단조. 이분 탐색이 유효하다.

`app/engines/loan/formulas.py`의 `loan_max()`가 이 의사코드를 그대로 구현한다.
반환값 `lo`는 실제 가능한 최대 대출액보다 항상 작거나 같은 보수적 하향값이며,
오차는 `ε`(기본 100,000원) 미만이다. `ε` 단위로 최종 절사할지는 아직 팀 결정
전이다.

## 부록 A-8. 여유자금(Buffer) 통합 (7·13·14)

```
Buffer = max(300,000원, 필수생활비 × 0.10)
```
7.2의 "최소 여유자금", 13.1의 "최소 현금흐름", 14.3의 "목표 월 여유자금"은 모두 이 값을 사용한다.

## 부록 A-12. DSR 포함 범위 (13.2, 14.1)

DSR 분자 = 기존 대출 연 원리금 + 신규(시뮬레이션 대상) 대출 연 원리금. 대출
가능액 탐색·상환가능성 점수 모두 신규 포함 기준으로 계산한다.

## 아직 없는 것 (열린 항목)

- **DTI 계산식이 SSOT 원문에 없다.** `loan_max()`는 `dti_limit_amount`를 이미
  금액으로 환산된 값으로 입력받기만 할 뿐, 그 환산 공식은 정의돼 있지 않다.
- **LTV·DTI·DSR 법정 상한표**(`policy/*.json` 등)가 저장소에 없다. `loan_max()`
  호출자는 이 상한을 어디선가 구해서 넘겨줘야 하는데 아직 그 출처가 없다.
- **금리 단위 계약**: `annual_rate`는 비율이다 (3.5% → `Decimal("0.035")`,
  `Decimal("3.5")` 아님). 금액 단위는 원, 기간 단위는 개월이다.
