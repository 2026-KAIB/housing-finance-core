# 현금흐름·비상자금·자금배분 엔진

## 책임

이 엔진은 주택구매 상품을 고르지 않는다. 사용자의 현재 금융 스냅샷과 선택적
월별 이력으로 다음 값만 결정론적으로 계산한다.

1. 안전 월소득과 안전 필수지출
2. 기존 부채상환 후 안전 월 잉여자금
3. 최소 월 현금흐름 Buffer
4. 사용자 위험지수와 비상자금 필요 개월
5. 비상자금 목표액·부족액·월 적립액
6. 예정지출과 비상자금을 제외한 주택자금 월 저축 가능액

## 계산 순서

```text
안전소득·안전지출
→ 월 잉여자금
→ 위험지수
→ 비상자금 목표액
→ 감당 가능한 비상자금 월 적립액
→ 주택자금 월 저축 가능액
```

## 주요 공식

```text
안전소득 = 최근 월소득 P25
안전지출 = 최근 월 필수지출 P75

안전 월 잉여자금
= 안전소득 - 안전지출 - 기존 대출 월 상환액

위험지수
= 0.35×소득변동성
+ 0.25×필수지출변동성
+ 0.25×부채부담
+ 0.15×가족·의료위험

비상자금 필요 개월 = 3 + 6×위험지수

비상자금 목표액
= max(안전지출×필요개월, 비정기 필수지출 P95)

Buffer = max(30만원, 안전 필수지출×10%)
```

## 결측 원칙

- 월별 이력이 부족하면 현재 입력값 또는 3~5개월 평균을 사용하고 `PARTIAL`로
  표시한다.
- 위험요소가 없으면 0으로 조작하지 않고 버전형 정책의 중립값을 사용한다.
- 현재 비상자금이 없으면 비상자금 부족액과 주택자금 월 저축 가능액을
  `None`으로 유지한다.
- 예정지출과 비정기 필수지출이 공용 API에 아직 없으므로 현재 Adapter는
  명시적인 가정과 함께 계산한다.

## 엔진 경계

- FastAPI, DB, Rule Pack, 상품 데이터를 직접 호출하지 않는다.
- 모든 금액과 비율은 `Decimal`을 사용한다.
- 대출·스트레스 엔진과 공유하는 Buffer 공식은
  `app.engines.safety.cashflow_buffer`를 단일 원본으로 사용한다.
- 현재 비상자금은 유동자산의 부분집합이며 별도 자산으로 더하지 않는다.
