# 생활 안정성 스트레스 테스트

## 목적

종합추천에서 선택된 대출·적금 계획이 금리 상승, 소득 감소, 생활비 증가에도
유지 가능한지 계산한다. 결과는 금융기관의 대출 승인 판정이 아니라 사용자의
구매 후 생활 안정성 점검이다.

## 규제 스트레스 DSR과의 차이

`app/regulations/stress_dsr.py`는 대출한도 심사를 위해 실제 금리에 법정
스트레스 가산금리를 더한다. 심사금리일 뿐 실제 월 상환액은 아니다.

이 디렉터리의 엔진은 추천이 끝난 뒤 사용자의 실제 상환액과 현금흐름에
서비스 시나리오 충격을 적용한다.

```text
규제 stress_dsr.py
→ 대출 가능액을 보수적으로 심사

생활 stress/engine.py
→ 선택된 대출·적금 계획이 충격에서 유지되는지 검사
```

두 값을 하나로 합치면 규제 심사와 생활 위험 설명이 모두 틀리므로 분리한다.

## 기본 시나리오

공식 설계안 §17은 충격 종류만 정의하고 수치는 정하지 않는다. 다음 값은
교체 가능한 MVP 내부 시나리오다.

- 현재 조건
- 금리 `+0.5%p`, `+1.0%p`, `+2.0%p`
- 소득 `-10%`, `-20%`
- 생활비 `+10%`, `+20%`
- 복합: 금리 `+2.0%p`, 소득 `-20%`, 생활비 `+20%`

호출자는 `StressTestInput.scenarios`에 다른 목록을 전달할 수 있다.

## 시나리오별 검사

1. 추천대출 원금으로 원리금균등 월 상환액을 재계산한다.
2. 소득 감소를 연소득과 구매 후 월소득에 동일하게 적용한다.
3. 생활비 증가를 구매 후 월지출과 필수생활비에 적용한다.
4. 스트레스 DSR이 서비스 안전 DSR 이하인지 검사한다.
5. 스트레스 현금흐름이 `max(30만원, 필수생활비 × 10%)` Buffer를 유지하는지
   검사한다.
6. Buffer를 남긴 뒤 추천된 월 적금 납입액을 유지할 수 있는지 검사한다.

결과는 `PASS`, `FAIL`, `UNKNOWN`으로 반환하며 실패 검사와 부족금액을 함께
제공한다.

## 금리유형 처리

- 변동금리: 생활 시나리오 금리 상승을 적용
- 전체기간 고정금리로 확인: 상환액에 금리 충격을 적용하지 않음
- 혼합형·주기형·금리유형 미확인: 재산정 시점을 모르므로 금리 시나리오 UNKNOWN

현재 기존 대출의 금리 재산정 주기가 MyData에 없으므로 금리 충격은 추천된 신규
대출에만 적용하고 기존 대출 상환액은 고정한다. 이 범위는 결과의
`scope_notes`에 기록된다.

## 아직 제외된 충격

공식 설계안 §17.4의 비정기 대규모 지출과 비상자금 유지 개월 계산은 현재
종합추천 계약에 비상자금 잔액이 연결된 뒤 추가한다. 값을 추측해 0원으로 넣지
않는다.
