# Loan engine tests

원리금 상환액, DSR, 대출한도와 금리 스트레스 계산을 공식 예제 및 수작업 기준값과 비교합니다.

`test_combination.py`는 여러 대출을 동시에 실행하는 조합안을 검증합니다. 가장 중요한
불변식은 **조합 총액이 개별 최대값의 합보다 작다**는 것입니다 — DSR·구매 후 현금흐름·
LTV는 차주 한 명당 하나뿐인 공유 예산이라, 다리별 한도를 더하면 그 예산을 다리 수만큼
중복 사용합니다. 실측 예시에서 개별 합 299,810,616원과 조합 233,406,364원의 차이
66,404,252원이 정확히 그 중복분입니다.
